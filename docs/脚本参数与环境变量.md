# 脚本参数与环境变量

脚本中心点击 **RUN SCRIPT** 后会打开输入窗口。点击 **RUN** 后，参数和环境变量会按脚本分别保存在本机，并在下次运行时预填。输入值使用 Windows DPAPI 按当前 Windows 用户加密，存放在 `%LOCALAPPDATA%\OnlyShell\script-inputs\`，不写入脚本定义、运行历史或 GitHub 同步数据；删除脚本时也会删除对应输入记录。

## 位置参数

脚本编辑器右侧的 **INPUT_TEMPLATE** 面板用 **+ ARG** 和 **+ ENV** 添加模板行。每项可设置名称、分组、类型、必填、敏感标记、默认值和选项；默认值单独用 DPAPI 加密保存，脚本定义只存字段结构。支持文本、数字、布尔、路径、选项和密码。拖动代码和模板之间的分割线可调整宽度。参数行顺序就是传给脚本的位置参数顺序，环境变量模板会自动出现在执行输入窗中；同一组名的连续字段会在运行窗口按组标题展示，留空则不分组。第一次运行时使用配置的默认值；之后优先预填上次实际运行时填写的值，未填写过的字段仍使用默认值。

运行窗口会按类型提供独立输入框、布尔/选项下拉框；密码或标记为敏感的值默认遮蔽，可临时切换显示。点击 **RUN** 前会校验必填、数字、布尔和选项值；路径类型保留为自由路径文本，以兼容本机 Windows 路径和远端 POSIX 路径。

每行输入一个参数，按行序传递。参数中的空格会保留，空行会忽略。脚本按各运行时的惯例读取：

| 运行时 | 读取方式 |
|---|---|
| Bash | `$1`、`$2` 等 |
| Python 3 | `sys.argv[1]`、`sys.argv[2]` 等 |
| PowerShell | 脚本的 `param($Name, $Count)` 或 `$args` |
| CMD | `%ONLYSHELL_ARG_1%`、`%ONLYSHELL_ARG_2%`；数量为 `%ONLYSHELL_ARG_COUNT%` |

CMD 暂用 OnlyShell 环境变量传递位置参数，避免把参数拼接进 `cmd.exe` 命令行。

## 环境变量

模板中的每个环境变量会显示独立的名称和值输入框；也可以在运行窗口临时添加环境变量。名称必须以字母或下划线开头，后续可包含字母、数字、下划线。值可以包含等号。可在脚本中使用 `$NAME`、`$env:NAME`、`%NAME%` 或 Python 的 `os.environ["NAME"]` 读取。

示例：

```bash
echo "greeting=$1"
echo "environment=$DEPLOY_ENV"
```

```python
import os, sys
print("greeting:", sys.argv[1])
print("environment:", os.environ.get("DEPLOY_ENV"))
```

```powershell
param($Greeting)
Write-Output "greeting=$Greeting"
Write-Output "environment=$env:DEPLOY_ENV"
```

```bat
@echo off
echo greeting=%ONLYSHELL_ARG_1%
echo environment=%DEPLOY_ENV%
```

## 安全说明

输入值虽以当前 Windows 用户可解密的形式加密保存，但运行中的脚本能读取它们；脚本如果主动打印变量，仍会进入输出历史。本机管理员可检查进程环境；远端 SSH 执行时参数和环境变量会随远程命令提交，具备相应权限的远程用户可能观察到它们。避免传入长期凭据，也不要在脚本中回显敏感值。加密记录绑定当前 Windows 用户和设备，迁移到其他用户或设备后不能直接解密。


## 多主机执行

终端目标为远程主机时，可使用 **RUN ON MULTIPLE** 选择多台主机。脚本会按选择列表顺序逐台执行，失败会记录到该主机的独立运行记录且继续后续主机；点击取消会停止当前执行并跳过后续主机。一次批量运行共用同一份参数和环境变量。当前不并发执行，也不支持把本机作为批量目标。
