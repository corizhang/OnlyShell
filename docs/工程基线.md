# OnlyShell 工程基线

## 已建立

- `OnlyShell.sln`：正式版解决方案；原有 `TerminalPoc/` 保持独立。
- `src/OnlyShell.App`：WPF 启动项目与首个工作台窗口。
- `src/OnlyShell.Presentation`：界面层，引用 Application 与 Terminal，不承载 SSH、持久化实现。
- `src/OnlyShell.Application`：用例层，放置 ViewModel/应用协调逻辑。
- `src/OnlyShell.Core`：主机、凭据引用、同步等领域模型和接口，目标框架为通用 `net10.0`。
- `src/OnlyShell.Infrastructure.*`：数据、SSH、系统秘密存储、同步适配层。
- `src/OnlyShell.Terminal`：终端适配边界；目前引用 PoC 中验证过的 VirtualTerminal 源码，避免拷贝两份上游代码。发版前须将固定版本与补丁迁入正式维护位置，并保留 Apache-2.0 许可。
- `design/prototypes/`：工作台、终端、SFTP 三张视觉概念图，采用直角边框、紧凑排版和代码工作区风格。
- 已接通的工作台流程：主机分组列表与搜索、新增/编辑/删除、详情展示；资料持久化至 `%LOCALAPPDATA%/OnlyShell/onlyshell.db`。支持密码与私钥路径两种 SSH 认证；密码可选择保存到 Windows Credential Manager，私钥文件内容与私钥口令不会复制进数据库或同步载荷。旧主机数据库会自动迁移，默认仍为密码认证。首次/变化的主机指纹需确认后才继续；终端支持多标签并在窗口关闭时清理会话。
- SSH 连接基线加入 15 秒连接超时、连接尝试重试及 20 秒 SFTP / 30 秒终端 KeepAlive；终端和 SFTP 每 2 秒检查连接状态。终端断线后可手动重连，原终端缓冲区保留但不会重放命令；SFTP 断线后提示重新建立会话。

## 依赖约束

```text
App → Presentation → Application → Core
App → Infrastructure.*
Presentation → Terminal → Infrastructure.Ssh → Core / SSH.NET
Infrastructure.* → Core
```

ViewModel 不直接依赖 SSH.NET、SQLite 或 GitHub API。SSH 密码可选进入系统凭据管理器，私钥使用本机路径，私钥口令只用于当前连接；这些资料不进入同步载荷。GitHub token 仅保存在本机受保护存储。

## 构建环境与依赖

- `.NET SDK 10.0.100` 起；`global.json` 允许使用同一 feature band 的更新 SDK。
- NuGet 包版本统一放在 `src/Directory.Packages.props`。该文件放在 `src` 下，避免把中央包管理规则泄漏到 PoC vendored 项目。
- Windows 10/11；WPF 项目目标为 `net10.0-windows`，领域/应用/SSH/数据项目尽可能使用通用 `net10.0`。

```powershell
dotnet restore OnlyShell.sln
dotnet build OnlyShell.sln
dotnet run --project src/OnlyShell.App/OnlyShell.App.csproj
```

## 下一步实现顺序

1. 补充 GitHub 同步的错误口令、跨设备版本冲突、令牌续期和异常恢复回归。
2. 完善设置工作区、诊断日志及同步状态反馈。
3. 补充 Windows 发布打包与发布前完整回归。

当前已实现 SSH 密码和私钥认证及终端会话；可选择将 SSH 密码保存在当前 Windows 用户的 Credential Manager 中，主机资料仅保存随机引用。私钥仅引用本机文件路径，私钥口令只用于当前连接且不保存。上述 SSH 凭据都不进入同步载荷。连接使用超时、重试和 KeepAlive；终端断线后可手动重连，SFTP 断线时可重新建立会话。SFTP 工作区采用本地/远程双栏文件管理器，本地盘符可切换；可多选文件或目录，通过中间按钮或跨栏拖放传输。目录传输会递归保留子目录结构，并作为单个可取消队列任务显示整体进度。支持逐项覆盖确认、顺序队列和取消。传输先写入临时文件，完成后再替换目标，取消或失败时会尝试清理当前文件的临时文件；目录传输取消时已完成文件和已创建目录会保留。符号链接会显示但不会参与传输或递归，避免跟随链接。下载保留远程后缀，删除非空目录会显示目录内容详情。递归删除和权限编辑尚未实现。终端使用 PoC 已验证的 VirtualTerminal 控件及 SSH 会话适配器。GitHub 同步工作区已接通 Device Flow 登录、指定私有仓库的加密推送/拉取及版本冲突保护；同步口令不保存，拉取采用整份配置替换并保留同 ID 主机的本地密码引用与私钥路径。设置导航仍显示阶段说明。当前 WPF 工作台使用直角边缘、紧凑布局和代码风格信息层级；主强调色为琥珀色，青绿保留给状态和语法提示。
