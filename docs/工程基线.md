# OnlyShell 工程基线

## 当前产品能力

- Windows WPF 桌面应用，目标框架 .NET 10；应用数据位于 `%LOCALAPPDATA%\OnlyShell\`。
- 主机管理支持分组、搜索、新增/编辑/删除、密码或私钥认证及 SSH 主机指纹确认。可选择将密码保存至当前 Windows 用户的 Credential Manager。
- 终端工作区支持 SSH、PowerShell、CMD 多标签；分屏后左右面板各自管理标签，可在分屏间拖动标签。终端支持鼠标选区浮动工具条、右键命令菜单、Ctrl+Shift+C 复制、Ctrl+Shift+V 粘贴（Ctrl+V 仍兼容）及 Ctrl+F 搜索；多行粘贴会先确认，普通 Ctrl+C 仍交由 shell/前台程序处理。快捷命令可分类、搜索和持久化到本机 JSON，支持 `{{name}}` 参数、必填校验、默认值、敏感输入掩码、命令预览和普通值可选记忆，插入时不发送回车。参数按原始输入替换，不自动进行 shell 转义。命令历史由 shell 原生处理（通常使用 ↑/↓，Bash/PowerShell 可用 Ctrl+R，CMD 可用 F7）。重启后恢复标签结构，但本地 shell 会启动新进程，SSH 标签需手动重连。
- SSH 终端提供 Linux 主机监控，当前包括 CPU、内存、Swap、根磁盘、负载、网络速率、运行时间、进程数及 SSH RTT，约每 3 秒采集。侧栏展示最近 3 分钟趋势，CPU/内存/根磁盘支持按会话调整告警阈值（默认 90%）；采样历史仅保存在当前会话内，暂不含 Windows 主机采集和历史导出。
- SFTP 提供本地/远程双栏浏览、盘符切换、多选、拖放、目录递归传输、顺序队列、进度与取消；失败任务可在同一主机重连后手动重试。上传/下载会保留同路径临时部分文件，重试前校验双方前缀 SHA-256 后续传，完成时再校验全文件 SHA-256。目录任务在应用运行期间记录已完成文件的路径、大小和修改时间，重试时跳过未变化的已完成文件；新增文件需重新选择目录，已选文件若被移走或删除会明确报错。单文件先写入临时目标，替换前校验文件大小和 SHA-256。符号链接不参与传输。权限编辑和递归删除暂未实现。
- 脚本中心支持本地 PowerShell、CMD、Python 3 与远程 Bash、Python 3；支持多级目录、搜索、类型化参数/环境变量模板、必填校验、DPAPI 加密默认值与运行输入、实时输出、取消和运行记录。多主机批量运行最多并发 3 台主机，并串行处理凭据提示和运行记录写入。默认值与运行输入不写入脚本定义、运行记录或同步数据；输出可能含敏感数据。详见 `docs/脚本参数与环境变量.md`。
- GitHub Device Flow 同步指定私有仓库中的加密主机配置。同步密钥由用户输入的口令派生；密码、私钥内容、私钥口令和私钥路径不进入同步载荷。同步采用整份配置推送/替换，不做字段级合并。
- 应用日志位于 `%LOCALAPPDATA%\OnlyShell\logs\`。设置页可导出环境信息与日志 ZIP；日志可能包含主机地址或异常上下文，分享前需检查。

## 工程结构

```text
src/
  OnlyShell.App/                    WPF 应用、启动、诊断与界面
  OnlyShell.Presentation/           ViewModel 与界面服务契约
  OnlyShell.Application/            应用协调逻辑
  OnlyShell.Core/                   领域模型与接口
  OnlyShell.Infrastructure.Data/    SQLite 持久化
  OnlyShell.Infrastructure.Secrets/ Windows 凭据管理器适配
  OnlyShell.Infrastructure.Ssh/     SSH.NET 与 SFTP 适配
  OnlyShell.Infrastructure.Sync/    GitHub API、Device Flow 与载荷加密
  OnlyShell.Terminal/               终端适配与脚本/监控执行器
TerminalPoc/                         验证项目及当前复用的 VT 源码
scripts/publish-windows.ps1          Windows x64 自包含发布脚本
.github/workflows/release-windows.yml GitHub Actions 双版本安装包与更新发布
installer/OnlyShell.iss              可选安装目录的 Windows 安装向导
```

依赖方向：`App → Presentation → Application → Core`；App 组合 Infrastructure；Presentation 经 Terminal 使用终端和 SSH 契约。ViewModel 不直接依赖 SSH.NET、SQLite 或 GitHub API。

## 开发与发布

要求 Windows 10/11 与 .NET 10 SDK，版本由 `global.json` 限定。

```powershell
dotnet restore OnlyShell.sln
dotnet build OnlyShell.sln
dotnet run --project src/OnlyShell.App/OnlyShell.App.csproj
```

生成 Windows x64 自包含免安装目录与 ZIP：

```powershell
.\scripts\publish-windows.ps1
```

输出位于 `artifacts\publish\win-x64\` 和 `artifacts\OnlyShell-win-x64.zip`。正式安装包通过 `.github/workflows/release-windows.yml` 在推送 `v*` 标签时构建：Self-contained 版内置 .NET 10 Desktop Runtime；Framework-dependent 版由 Velopack 在缺少运行时时联网引导安装。两版使用单独的更新通道和可选择目录的 Inno Setup 向导；代码签名尚未配置。发布流程与验收要求见 `docs/发布Windows版本.md`。
