# OnlyShell visual prototypes

These three generated concept images define a first visual direction for the product.

1. **Workbench** — host navigation, recent sessions, transfer overview, sync state, and quick connect.
2. **Terminal** — host tabs, large high contrast VT area, session controls, and connection status.
3. **SFTP** — remote path navigation, file list, and transfer queue.

Shared direction: square corners, compact spacing, code-workspace hierarchy, charcoal-black surfaces, thin separators, restrained amber focus accents, green/cyan connection and syntax colors, keyboard-first navigation, readable Chinese labels, and a true black terminal canvas. Treat values and labels shown in the concepts as illustrative. V1.0 does not include port forwarding, Telnet, command snippets, or other features omitted from the agreed scope.

These images are visual references, not pixel-perfect implementation contracts. The initial WPF shell implements the workbench structure and angular palette; later screens should reuse those resources and prioritize accessibility, DPI scaling, and terminal readability.
